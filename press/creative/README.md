# App Store 創意素材（產品頁標題／搜尋結果）—— 產生器

iOS 27 起 App Store 的產品頁有**標題（header）**、搜尋結果可以放**主視覺**。這裡產生那幾張圖與兩支影片，
輸出到主 repo 的 `store_assets/creative/<語言>/`（上傳方式見那裡的 README）。

```bash
python make_creative.py --preview          # 三張 PNG × 五語（珊瑚版），另出安全區檢查圖到 build/creative/preview/
python make_creative.py header ja          # 只出某幾個（版位、語言可混著寫）
python make_creative.py --night --paper    # 夜色版／紙色版（產品頁 A/B 測試的備案；可加 --coral 三個一起出）
python make_creative.py --video --coral --night --paper   # 兩支影片 × 三配色 × 五語（Remotion，一支約 3–5 分鐘）
python make_creative.py --video header en --frames=38,60,600   # 只出幾格靜態圖試看（build/creative/stills/）
python make_creative.py --finalize         # 只重做影片的配樂與色彩標記
python loop_music.py 6                     # 重做 18 秒循環配樂（六小節，build/creative/loop_18s.wav）
```

| 檔案 | 做什麼 |
|---|---|
| `make_creative.py` | 版面（設計單位寬 1920，用 zoom 放大到輸出像素）、渲染、檢查圖、影片的底圖與亮格 |
| `pixel_icons.py` | 讀 `lib/core/design/pibook_album_icons.dart` 的像素原稿 → SVG（一格一個方塊，放多大都不糊） |
| `photos.py` | 從示範圖庫快取（`build/store_demo_cache`，Pexels 授權）挑照片、縮到長邊 1600 |
| `loop_music.py` | 影片配樂：沿用預覽影片配樂（`../video/music.py`）的樂器與和弦，一張照片一小節、首尾無縫 |
| `../remotion/src/creative/` | 影片版（獨立入口，不動預覽影片的 `src/index.ts`） |

## 規格與安全區

依 Apple〈Creative assets specifications〉與官方 Sketch 範本（`creative_assets-templates.sketch`，
2026-10-06 讀；範本本身不放進 repo）：

| 版位 | 輸出 | 安全區（像素） |
|---|---|---|
| 標題 21:9 | `header_3840x1646.png`／`.mp4` | x 1097–2743、y 493–1154（置中） |
| 搜尋結果 3:2 | `search_3840x2560.png`、`search_3240x2160.mp4` | x 836–3004、y 765–1795（置中） |
| 通用 16:9（只收 PNG） | `universal_5244x2950.png` | x 1921–3323、y 660–1622（**偏上**，不是置中） |

## 畫面（v2，2026-10-06）

第一版「左邊整理好的圖庫、右邊亂丟的照片、中間一張被左滑保留的卡」被使用者否決：比喻沒人看得懂、
影片只有滑卡保留、跟商店裡其他滑卡整理 App 沒有分別。v2 的主角是**相簿軌**（拍簿獨有的「點一下就歸檔」
＋自訂像素相簿圖示）：App 底部那條軌放大成橫跨畫布的相簿架，照片正落進其中一格，皮皮趴在軌道上。

## 畫面（v3，2026-10-07）—— 產品頁面測試的三個版型

使用者看了 v2 在 App Store 裡的樣子：「整個版面太空洞、很樸素，像 prototype」。原因：v2 的東西全擠在安全區裡、
又都很小，而搜尋結果在 iPhone 上**整張 3:2 都看得到**（使用者截圖），安全區外的上下大片空白就露出來了。
v3（`make_v3.py`）三個方向都把安全區外填滿，放進產品頁面最佳化比轉換率：A 照片牆（夜藍、壓暗的整面圖庫當底，
巴哥犬從空出的那一格被抽出來）、B 大字海報（珊瑚滿版＋相簿圖示單色底紋、軌道出血、照片排隊落下）、
C 手機破框（手機站在軌道上、軌道從手機底部長出來；軌道以下一塊珊瑚地板＋隱私承諾署名）。
C 的手機螢幕照 App 實機錄影量的幾何重畫（卡片位置、圓角、頂列），頂列只放「1 / 10」，五種語言共用。
規矩表沿用下面那張。v3 影片（`make_v3.py --video`）沿用 `CreativeLoop.tsx`：A、B 是排隊模式（A 沒有排隊的格子、照片從牆上的洞進場，`entry`），C 是新的手機模式（`mode: 'phone'`：卡片裁在「螢幕到相簿軌上緣」之內，飛出去那張不裁）。

## 這套圖的規矩（每一條都是做的時候踩過或量過的）

| 規矩 | 為什麼 |
|---|---|
| **每一種尺寸都要看得到相簿軌**，而且在安全區裡 | 使用者裁示：相簿軌與自訂圖示是拍簿的特色，沒有它就跟別的滑卡 App 一樣 |
| 相簿軌貼著安全區下緣；字在左上、主角照片在「狗狗」那格正上方 | iPhone 直向只看得到安全區那一條，那一條本身要是完整的一張圖 |
| 軌道的顏色、圓角、格距照 App 實機錄影量（軌底 #FCFAF8、格子 #F0EAE1、點到的那格 #A0ABB6） | 要讓用過 App 的人一眼認出是同一條 |
| 圖示直接讀 Dart 原稿，不截圖、不重畫 | 截圖放到 4K 會糊；重畫會走樣 |
| 相簿名稱放不下就縮（`FITW_JS`），不折行、不截斷 | 跟 App 的相簿軌一樣 |
| 標題字欄的右緣從主角照片（轉了 9° 的外框）左緣再退 24 推出來 | 英文、日文的標題比中文長，第一版撞到巴哥犬 |
| 排隊照片的路線（二次貝茲 `path`）先在高處往右、再往下落 | 第一版的路線掠過標題右上角 |
| 兩側落下的照片碰到字或主角就自動跳過（`keep_out`） | 第一版有一張咖啡壓到標題 |
| 觸控圈不畫在靜態圖上 | 圈會蓋住「狗狗」兩個字；影片裡才短暫出現 |
| 大標「點一下歸檔／滑一下刪除」，強調色只給歸檔 | 「滑一下保留」等於沒說（內建相簿滑一下也只是看下一張）；刪除放第一句太負面（使用者 2026-10-07） |
| 杯子上印著真實店家品牌的照片不用（`boba_pair`、`boba_cheers`） | 商店素材不放第三方商標 |
| 珊瑚底、米白字、淡金強調；陰影用偏紅的深色，不加發光 | App 圖示的品牌色；使用者裁示：克制、不要 AI 塑膠感 |
| 字型由語言決定；韓文標題用黑體 | 與商店截圖同一套（`make_boards.py`） |

## 影片版

- 版面不在 React 裡重排：Chrome 烤兩張底圖 —— 一張**不畫排隊的照片、哪一格都沒亮**，一張**三個目標格都亮著**；
  從第二張把那三格裁下來（連同粗體名稱與皮皮的手）。Remotion 只動照片，亮格用裁下來的圖淡入淡出，
  所以跟靜態 PNG 逐像素相同（第 38 格與 PNG 的差異只有主角上方那顆小星星被照片蓋住的 41×39 像素）。
  v1 讓 Remotion 直接載整面照片牆，4K 多分頁渲染時照片還沒解碼就截圖，成片裡出現白色空格。
- 一張 3 秒：0.30 點一下（觸控圈、那格亮起）→ 0.56–0.70 靜止＝靜態圖那一刻 → 0.70 照片往格子落 →
  1.00 到格子正上方 → 1.12 縮進去、看不見（配樂放「收進相簿」音效）→ 1.22–2.05 後面的遞補 → 2.10 那格熄掉。
  六張一輪＝18 秒。**海報影格選第 38 格（0.63 秒）。**
- **從隊伍後面上來的一定是畫面上沒有、剛剛也沒收過的照片**：隊伍同時排三張，第 k 張收走時進場的是第 k+3 張，
  所以一輪至少六張（`VIDEO_ITEMS`）。也不能跟兩側落下的照片重複。三張一輪時剛收進去的那張下一秒就又冒出來。
- 三個配色都有影片（底圖照各自的主題烤，照片陰影照各自的 `.fly`：`FLY_SHADOW`）。
- 照片**先到位、才淡掉**：半透明的照片只能出現在目標格上。試過邊飛邊淡，照片疊在隔壁那格上像收錯相簿。
- 目標只用「狗狗」與左右緊鄰的兩格。試過「旅行」（左邊第二格），一路得從「美食」上面掠過。
- 往右的目標先往右、再從上面落進去（不從「狗狗」那格橫切過去）；往左的目標直線斜落
  （先往左會劃過標題的尾巴）。
- 60fps：落進格子那 0.4 秒在 30fps 只有 12 格。
- 搜尋結果影片用 3240×2160，不用 3840×2560：後者超過 H.264 level 5.2 的畫面上限（9,437,184 像素）。
- 配樂：80 BPM，一小節＝一張照片（C – G – Am – F 一路循環，六小節最後的 G 接回 C）。三輪一起算殘響、只取中間那輪，
  而且三輪放的是**同一份**音（`music.py` 的樂器帶隨機相位，每輪各算一次接縫會喀一聲）。
  響度約 −20 dBFS：Apple 預設靜音，打開時只是背景質感。
- 驗收：首格與末格差異 < 0.1、沒有單格突刺（缺圖或閃白），見 DIRECTOR_SCRIPT §8。
